## 🚀 快速使用

### 查看 HTML 培训讲义
```bash
# 完整培训教程
open docs/claude-code-training.html

# 命令速查手册（新增）
open docs/claude-code-commands.html
```

### 查看 PPT 演示文稿
```bash
# 用浏览器打开，支持键盘操作
open slides/claude-code-training-slides.html
```

**PPT 快捷键：**
- `←` `→` 或 `空格`：切换页面
- `S`：显示演讲者备注
- `F`：全屏模式
