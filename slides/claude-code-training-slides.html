Claude Code CLI 是什么？

一句话定义：
一个在终端运行的 AI 编程助手，能直接操作你电脑上的文件，
看到你的整个项目，帮你写代码、改代码、修 bug。

📖

✏️

分析

理解报错并给出方案

📋

规划

帮你拆解开发任务

为什么选择 Claude Code CLI？

对比项 网页版 AI IDE 插件 Claude Code CLI
能看到项目吗 ❌ 只能看粘贴内容 ⚠️ 只能看当前文件 ✅ 能看整个项目
能直接改文件吗 ❌ 需要手动复制 ⚠️ 部分可以 ✅ 直接读写
能执行命令吗 ❌ 完全不能 ❌ 不能 ✅ 可以运行
能分析报错吗 ⚠️ 需要粘贴 ⚠️ 需要手动 ✅ 自动读取
结论

如果你想系统开发一个项目，而不是只要代码片段，Claude Code CLI 是更好的选择

新手最容易犯的 5 个错误

错误 问题 正确做法
一次生成全部 质量差、难调试 分步开发，一次一个功能

实战项目：个人待办清单

✅ 为什么选择待办清单？

  • 功能直观，你每天都在用
  • 范围可控，核心功能就 3 个
  • 技术覆盖全面（HTML/CSS/JS）
  • 即时反馈，立竿见影
  • 可扩展，后续可加功能

📋 最终成品

  • 输入框 + 添加按钮
  • 任务列表（可标记完成/删除）
  • 数据保存在浏览器中
  • 简洁美观的界面

技术栈：纯 HTML + CSS + JavaScript

第 4 步：生成 MVP

💡 什么是 MVP？

MVP = Minimum Viable Product（最小可行产品）
用最少的代码，先让东西能跑起来

✅ 为什么要先做 MVP？

  • 快速验证想法
  • 尽早发现重大问题
  • 建立信心和成就感
  • 便于后续增量开发

📝 提示词示例

请帮我完成最基础的版本： 1. index.html：标题+输入框+按钮 2. styles.css：最基础的样式 3. app.js：暂时留空 要求：先让页面能显示出来

第 6 步：运行、报错、修复

报错时该怎么办？

  1. 不要慌！错误信息是解决问题的线索
  2. 复制完整错误信息
  3. 告诉 AI 上下文：你在做什么、期望什么、实际发生什么
  4. 让 AI 解释原因、给出方案、验证修复

📝 提示词示例

我在测试添加任务时遇到错误： 错误信息： Uncaught TypeError: Cannot read property 'addEventListener' of null 我正在做什么：点击添加按钮 期望结果：任务出现在列表中 实际结果：没有反应 请解释原因并修复

新手最常问的 5 个问题

Q1：我不会写代码，能用吗？

可以，但你仍需能描述清楚需求、判断对错、持续追问

Q2：我该一次性生成全部吗？

绝对不要！分步开发，一次一个功能

Q3：为什么输出不符合预期？

通常是描述不够具体，给出更详细的需求或参考示例

Q4：看不懂报错怎么办？

把错误信息完整复制给 AI，让它解释

Q5：怎么判断 AI 写得对不对？

运行测试、让 AI 解释逻辑、对比原始需求
